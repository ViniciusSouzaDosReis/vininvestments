# Vini Investments

Uma plataforma de investimentos e banking construída como campo de testes, um cenário
próximo o bastante da realidade para os problemas serem de verdade, e livre o bastante
para eu errar à vontade.

## A premissa

Esse é o meu projeto impossível.

Ele não vai seguir as melhores práticas o tempo todo, e isso é proposital: a ideia é ter
um lugar onde eu possa testar tecnologias diferentes sem a pressão de acertar de primeira.
A evolução dele também não precisa ser linear, ele tende a refletir o meu momento de
carreira, e não um roadmap.

A expectativa é olhar para trás daqui um tempo e conseguir enxergar todo o caminho que
percorri no processo.
